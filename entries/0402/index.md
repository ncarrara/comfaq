## Question

The Sepulchral Animus rules allows a modifier with the following wording: "Once per turn, before making a casting roll, any liche priest within a Mortuary Cult army..." Does that mean the ability can be used once per Priest or only once per army?

## Ruling

Once per Priest. The use of "any Liche Priest" indicates that there is no limit on the number of Liche Priests using the ability, as it relates to a unit entry, and not models.
