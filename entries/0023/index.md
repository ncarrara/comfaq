## Question

Does a champion in a unit with a single Rank open a new rank when refusing a challenge.

## Ruling

No - A challenge can only be declined if all models able to accept it are able to retire to positions outside of the fighting rank, without creating a new rank.

In the case of a single rank unit engaged in the front, this is not possible and the challenge must be accepted. If the unit is engaged in one flank only, the challenge can be declined as the champion or character is able to retire to the other flank.

In the case of a unit with two fighting ranks (due to press of battle), the challenge can only be declined if there is a third rank the character or champion can join.
