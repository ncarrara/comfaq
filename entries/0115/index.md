## Question

When a unit that causes Terror declares a charge, when is the Leadership test taken and how is a failed test resolved? How does this interact with multiple charges?

## Ruling

When a unit that causes Terror declares a charge, the target must immediately take a Leadership test, before any further charges are declared. If the test is failed, the unit must declare Flee as its charge reaction. The flee move is resolved as normal, together with the other charge reactions. In the case of multiple charges, as the unit has declared Flee, it flees from the charging unit with the highest Unit Strength, following the normal rules for multiple charges. Note that Terror tests are not limited to one, so if multiple units with Terror charge, you have to pass multiple tests.
