## Question

Is there a difference between rules that say you suffer a wound and ones that say you lose a wound?

## Ruling

Suffering a wound allows armor and ward saves if not specifically ruled otherwise. Losing a wound means the model loses the wound without any saves allowed. Note that you can use the regeneration special rule when a wound is lost (except for Unstable, where regeneration is not allowed).
