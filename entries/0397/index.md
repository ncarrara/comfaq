## Question

If a unit loses models during its movement, e.g. by moving through a fanatic, dangerous terrain, peril tests or a vortex, when are models removed?

## Ruling

Remove models right after each damage-dealing source encountered. A reduction in the unit size might affect whether or not it encounters terrain, models or objects behind the first damage-dealing source, and the following wheels might be affected if the unit width is reduced. Charge roll is still affected by terrain based on whether it would be contacted before moving, taking the low dice if the charge path is expected to cross terrain before moving. If the moving unit is a fanatic, he is immediately removed from play and does not move any further if slain.
