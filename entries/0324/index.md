## Question

How is Regeneration applied for a model that suffers an unsaved wound with the Multiple Wounds (X) special rule, if the model has less than X Wounds remaining?

## Ruling

An unsaved wound with the Multiple Wounds (X) special rule causes the target to lose X Wounds (instead of 1), lost simultaneously. If the model has fewer than X Wounds remaining, it loses all its remaining Wounds, and excess wounds have no further effect (no spillover), but will count for Overkill in a Challenge. The model then attempts to Regenerate the lost Wounds.

If a troll with 3W left suffers an unsaved wound with Multiple Wounds (5), it loses its 3 remaining Wounds, then attempts to regenerate the 3 lost Wounds. The 2 potential wounds in excess have no effect.
If a skeleton suffers an unsaved wound from a cannonball with MW (D3+1), it loses it single Wound, then attempts to regenerate it. The other potential wounds in excess have no effect.
