## Question

A fighting rank cannot contain more characters than it does rank and file models. In the case of a unit with the Press of Battle rule, does this include rank and file models in a second fighting rank?

## Ruling

No. No single fighting rank can contain more characters than it does rank and file models. It doesn’t matter how many fighting ranks a unit might have.
