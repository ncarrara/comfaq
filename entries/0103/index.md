## Question

The rule say that Magic Resistance doesn't stack. Does this count only for multiple models or does it include single models?

## Ruling

Magic Resistance from various sources or multiple items doesn't stack for single models unless it is explicitly stated (like Obsidian Lodestone stacks with itself)
