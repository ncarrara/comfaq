## Question

If a Doom Diver fires indirectly, do you allow for a -d3 instead of the ballistic skill and then another d3 directional correction?

## Ruling

Yes, the second part of the Doom Diver Rule referes to the indirect fire part of the bombardment rule of 225, so the first part gets applied too.
