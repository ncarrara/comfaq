## Question

Q: Redress the Ranks requires models to be added (or subtracted) from the left and right side of the unit "as equally as possible." What happens when it is only possible to add models to one side of the unit?

## Ruling

Redress the Ranks can at most add one more model to the left side than the right (or vice versa). If one side is blocked, then a unit can only redress to add a single model to the opposite side.

When removing models, the last models to remove must be the characters, then the command group, always keeping the standard bearer in the front rank and as close to the centre as possible. Command group models removed from the front rank must go to the second rank (and third in case of a single column). Characters removed from the front rank must go to the rear rank. The player choses the position of all models in their respective back ranks. When adding models to the front rank, the opposite order must be followed: first the command group, then the characters, before rank and file models. The position of added models can be chosen by the controlling player, but must respect the positioning rule for the command group and for characters: standard bearer as close to the centre as possible, command group models to either side, characters anywhere in the front rank. Note that characters may be placed among the command group.
