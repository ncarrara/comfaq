## Question

What Armour Value is used if a model equipped with hand weapon and shield  and the parry spcial rule is engaged in combat and suffers wounds before Step1.1 of his Combat? Can the model use Parry?

## Ruling

Use the same Armour Value that would be used if the model were not engaged in combat. The model will use his shield if he has one, but Parry does not apply as his weapon choice has not yet been made for that combat round.
