## Question

Big Smartz: If a unit failed a stupidity test but succeeds another one before my next start of turn sub-phase, is the unit still stupid ?: Can the unit wound automatically?

## Ruling

No, a stupid unit ceases to be stupid if it succeeds a stupidity test.
