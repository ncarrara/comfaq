## Question

Hatred applies during the first round of combat. If a unit that's already in combat is charged by a new unit, does that count as a new combat for the purpose of Hatred?

## Ruling

Only for the charging unit in this example. The first round of combat is relative to each unit, and for Hatred to be used it must be the first round that the unit with Hatred is engaged in that combat.
