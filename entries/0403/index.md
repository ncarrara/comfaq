## Question

Some special rules use the wording majority of the models (Warband, Immune to Psychology, Frenzy, Run with the Pack as examples). How do these special rules work when there is no majority, and the unit is split half?

## Ruling

Unlike Motley Crew, all these rules are optional or buffs to existing rules. For Motley Crew, the rules stop working on a draw, but these rules are full functional. Thus, you need to have more than 50% of the models qualifying for the use of the rule to achieve a majority and make the rule work.
