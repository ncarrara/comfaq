## Question

When a Goblin Hewer shoots using the Whirling Death special rule, does it add a D3 modifier to the number of shots rolled for each rank or file, or just a single D3 modifier?

## Ruling

Roll an Artillery dice, plus an extra D3 per rank or file of the unit, depending upon which arc the weapon is shooting into.
