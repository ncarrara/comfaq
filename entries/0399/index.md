## Question

When multiple templates would hit a unit in the same shooting sequence (for eample results 2-6 of the miscast table with the dark coven rule or from Sky Lantern bombing), how do you resolve these templates?

## Ruling

Resolve the templates at the same time. Every hit is assigned to the model that is actually hit, leading to possibly single models suffering multiple hits. Note for single-wound models, this will possibly cause excess damage, which is then lost. Roll for each model on its own.
