## Question

A unit with random movement arrives as reinforcements or with the ambushers special rule during the compulsory moves sub-phase. Can this unit move during this sub-phase ?

## Ruling

Yes, it did not move yet using its random movement rule. Please note that if the model is able to make contact with an enemy unit it may do so and counts as having charged.
