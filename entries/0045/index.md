## Question

If a unit is returning after pursuing /charging off the battlefield, does it need to be placed more than 8" away from enemy units as per ambushers rules.

## Ruling

No, this is restriction is when the position is chosen. The position for returning is as close as possible to the point at which it left the battlefield in a legal position (e.g. 1" away from enemy units and not on top of own units
