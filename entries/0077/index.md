## Question

Some abilities grant bonuses to a characteristic, up to a maximum value. Some grant bonuses with no mention of a maximum value. When used together, how do they interact? How does it interact with Strike Last, Strike First or abilities that set characteristics to a certain value?

## Ruling

Set the Initiative first to the value (1 in case of Strike Last). Any limitation is applied at the end of characteristic calculation. If there are no limitations on the characteristic from any source, you can go above 10. Note that no characteristic can go below 0 (see pg. 97 Characteristics of Zero). Models with Initiative 0 attack in Initiative order, after all attacks with initiative 1, including stomp attacks.
